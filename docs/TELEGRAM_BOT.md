# Telegram Admin Bot

> **Служба:** `hydra-tg-admin` · **Доступ:** только Telegram user ID, указанный
> как Admin Chat ID

Бот — админ-интерфейс к тем же функциям, что TUI и CLI.

## Настройка

Настраивается в TUI, раздел **Telegram**:

1. **Admin-токен** — создайте бота у [@BotFather](https://t.me/BotFather) и
   вставьте выданный токен.
2. **Admin Chat ID** — узнайте свой ID у
   [@userinfobot](https://t.me/userinfobot) и укажите его.
3. **Запустить Admin-бота** — HYDRA установит и запустит службу
   `hydra-tg-admin`.

Оба значения обязательны: без токена или без Chat ID запуск отклоняется.
Управлять службой можно и напрямую:

```bash
sudo systemctl status hydra-tg-admin
sudo systemctl restart hydra-tg-admin
sudo journalctl -u hydra-tg-admin -n 100 --no-pager
```

## Интерфейс

Команда `/start` или `/menu` открывает кнопочный Control Center:

```text
   /start · /menu
        │
        ├── Система ──────────── состояние VPS и служб
        │
        ├── AntiDPI ──────────┬─ сводка: баны и статистика улик
        │                     ├─ Подробнее ──── счётчики улик и источников
        │                     ├─ Блокировки ──┬─ постранично, все до одной
        │                     │               └─ строка → карточка адреса
        │                     └─ запуск / остановка          ⚠ подтверждение
        │
        ├── Honeypot ─────────┬─ порт ловушки и её баны
        │                     ├─ запуск / остановка          ⚠ подтверждение
        │                     └─ разбан IP                    ⚠ подтверждение
        │
        ├── Fail2ban ─────────── сводка и подробности каждого jail
        │
        └── Уведомления ──────┬─ переключатели категорий
                              ├─ Только блокировки
                              └─ Тихие часы ─── окно тишины ±1 час
```

Действия, помеченные ⚠, требуют явного подтверждения нажатием.

### Навигация

`⬅️` — на уровень выше, `🔄 Обновить` — перечитать экран, `🏠 Меню` — в главное
меню; списки листаются постранично (`◀️ стр. 2/5 ▶️`).

### Карточка адреса

Пришлите боту IPv4 или IPv6 сообщением — откроется карточка: GeoIP и ASN,
статус в AntiDPI (заблокирован с остатком срока, протоколом и причиной,
или улик нет), статус в Honeypot и кнопки блокировки и разблокировки.
Строки списков открывают ту же карточку.

Команды доступны и напрямую:

| Команда | Действие |
| :--- | :--- |
| `/start`, `/help`, `/menu` | Открыть Control Center |
| `/system`, `/status` | Состояние VPS и служб |
| `/antidpi` | Состояние и статистика улик AntiScan |
| `/honeypot` | Состояние ловушки |
| `/fail2ban` | Сводка jails |
| `/notifications`, `/notify` | Настройки категорий уведомлений |
| `/unban <ip>` | Снять блокировку с адреса |

Изменение состояния защитных служб и разбан требуют подтверждения.

### Экран AntiDPI

`/antidpi` показывает состояние службы, число активных и бессрочных банов,
счётчик событий с давностью и источником последнего, статистику доставки
уведомлений и — если он был — отказ firewall при попытке бана. Каждый бан
выводится с флагом GeoIP, ASN/owner, остатком срока, причиной на русском,
протоколом и номером offense; кнопки разбана подписаны остатком срока.
Списка «под наблюдением» нет: улика либо доказана и банит, либо не
существует.

Кнопка `🧾 Подробнее` открывает детальный вид: whitelist, число адресов под
учётом, рейтинг сигналов и источников и полный список блокировок.

## Уведомления

Независимо переключаются master switch, AntiDPI, Honeypot, Fail2ban BAN, события
UNBAN и системные уведомления. Настройки атомарно сохраняются в state.

### Уровень шума

- **Только блокировки** — доставляются лишь события с применённым действием
  (`BAN`, `UNBAN`, `BLOCK`, `ERROR`, `FAILURE`); предупреждения подавляются.
- **Тихие часы** — окно по времени сервера (по умолчанию 23:00–08:00, кнопки
  ±1 час, корректно через полночь). В окне доставляются только те же события с
  применённым действием.
- Выключенная категория сильнее обоих фильтров: если AntiDPI отключён, не придёт
  и BAN.
- Honeypot уведомляет только после подтверждённого firewall-бана, а не при одном
  TCP connect.
- Статистика `attempted`/`delivered`/`failed` отличает отсутствие угроз от сбоя
  доставки.

### Кнопка блокировки в карточке адреса

Кнопка `🚫 Заблокировать` банит IP **бессрочно**, до ручного разбана
(TTL-лестница — у банов детектора, см. [ANTIDPI.md](ANTIDPI.md)).

- Callback принимается только от настроенного администратора.
- Повторное нажатие не создаёт новый offense.
- Адрес из whitelist через кнопку заблокировать нельзя.

## Безопасность

- IP валидируются и передаются внешним программам только как argv.
- Динамический текст экранируется для Telegram HTML.
- Токен не выводится при HTTP-ошибках.
- Тяжёлые status/systemd-операции выполняются вне asyncio event loop.
- Изменение состояния служб и снятие блокировок требуют подтверждения.
- Мониторы Fail2ban и Honeypot переживают logrotate и не воспроизводят старые
  события.

> [!CAUTION]
> Бот работает от `root`, а его токен является **root-equivalent секретом**. Не
> добавляйте бота в группы и перевыпустите токен при любом подозрении на
> компрометацию.
