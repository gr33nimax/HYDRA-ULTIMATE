# Документация HYDRA

> [!IMPORTANT]
> Ветка `legacy-main` заморожена и больше не поддерживается.
> Актуальная документация, исправления и релизы находятся в ветке `dev`.

Полный набор технической документации проекта. Версия документации
соответствует ветке репозитория.

```text
   развернуть сервер            эксплуатировать            развивать
   ─────────────────            ─────────────────          ─────────────────
   UPGRADE.md                   CLI.md                     ARCHITECTURE.md
   установка и обновление       команды и коды ошибок      слои и инварианты
        │                            │                          │
        ▼                            ▼                          ▼
   REFERENCE.md                 ANTIDPI.md                 PLUGIN_DEVELOPMENT.md
   порты, службы, пути          защитный контур            добавление плагинов
                                     │
                                     ▼
                                TELEGRAM_BOT.md
                                уведомления и разбан
```

## Состав документации

### [ARCHITECTURE.md](ARCHITECTURE.md)

Модель системы, слои и направление зависимостей, пути входящего трафика, TLS-
мультиплексор, транзакционный жизненный цикл применения, контракты плагинов,
правила работы с state, безопасность, release-модель и границы текущей версии.

### [CLI.md](CLI.md)

Исчерпывающий справочник headless CLI: каждая команда и параметр, требования к
`root`, поля JSON-ответов, стабильные коды ошибок и типовые сценарии
восстановления.

### [UPGRADE.md](UPGRADE.md)

Чистая установка через `bootstrap.sh`, запуск из исходников и транзакционное
обновление рабочей VPS одной командой через `updater.sh`: гарантии updater,
порядок отката, состав снимка и процедура ручного восстановления.

### [REFERENCE.md](REFERENCE.md)

Операционный реестр: модули, systemd-службы, каталоги, файлы состояния, журналы,
сетевые порты, схема persisted state и переменные окружения установщиков.

### [ANTIDPI.md](ANTIDPI.md)

Поведенческий контур обнаружения протокольной разведки: поток данных, атрибуция
внешнего IP через source relay, сигналы и веса, двухуровневый scoring, политики
ALERT и BAN, UDP spoof-safety, протокольная матрица, эксплуатация и границы
возможностей.

### [TELEGRAM_BOT.md](TELEGRAM_BOT.md)

Настройка и интерфейс административного бота, категории уведомлений, кнопка
блокировки в ALERT и требования безопасности к токену.

### [PLUGIN_DEVELOPMENT.md](PLUGIN_DEVELOPMENT.md)

Поддерживаемый путь расширения: класс плагина, декларация возможностей в
`PluginMeta`, вклад в конфигурацию через `ConfigFragment`, правила для адаптеров
и обязательный набор тестов.

## Соглашения документации

- Все команды приведены в виде, пригодном для копирования; `sudo` указан там, где
  он действительно требуется.
- Значения портов и путей — заводские значения по умолчанию. Фактические
  значения хранятся в state и проверяются командой `hydra status`.
- Блоки `[!WARNING]` и `[!CAUTION]` отмечают операции, способные привести к
  потере доступа или данных.
- Документация описывает поведение ветки, в которой она находится. При
  расхождении с кодом источником истины является код и тесты.
